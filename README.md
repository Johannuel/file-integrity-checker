# File Integrity Checker

Herramienta en Python para detectar cambios en archivos usando hashes SHA-256.

## Requisitos

- Python 3

## Uso

```bash
python integrity_check.py init archivo_o_directorio
python integrity_check.py check archivo_o_directorio
python integrity_check.py update archivo_o_directorio
```

## Qué detecta

- Archivos modificados
- Archivos nuevos
- Archivos eliminados
